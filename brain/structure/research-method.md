For serious research, build the request from these modules (1→5 in one message), then audit the answer with module 6.

1. **Opening** — frame neutrally. Ask for a map of the territory, not a verdict. Don't pre-load the conclusion; don't ask for "best practices". Surface contested/unsettled areas side by side.
2. **Domains** — enumerate the 8-15 macro-areas to cover with sub-aspects. The model can't fill a category you never asked for. Calibration: 5-7 light · 8-12 standard · 13-18 deep · 18+ split sessions.
3. **Citations** — for every claim, a primary source with link, author/org, date. Acceptable: official docs, peer-reviewed papers (DOI), named talks, dated posts by a named author, filings, postmortems. Not acceptable: "reports indicate…", "most experts say…", Wikipedia for contested topics, AI summaries of AI summaries. If no primary source: write "primary source unavailable".
4. **Disclaimers** — where data is thin, declare it rather than filling with confident speculation. Mark "emerging, contested" + timeframe; "documented but not independently verified"; "no public data available". Honest limitation notes raise value.
5. **Emerging patterns** — end with "patterns not explicitly requested": 5-10 relevant trends not in module 2, each with context, 1-2 sources, and a maturity tag.
6. **Post-research audit** — check density, spot-check 5-10 citations (>20% fail ⇒ treat whole output as suspect), expect 2-5 honest disclaimers, categorise findings 1-5, and triage gaps A (run another session) / B (closes during work) / C (needs direct consultation). Anti-demoting discipline: re-interrogate anything you labelled "minor/edge case".

The loop is: first pass → audit → identify gaps → closing pass. Use for complex, shifting domains; not for simple factual lookups.
